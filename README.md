# دليل موقع تطبيق الغريب

## هيكل الموقع

تم تحسين تطبيق "الغريب" للدردشة ليتضمن الملفات التالية:

### 1. ملفات الواجهة (HTML)

- **index.html** - الصفحة الرئيسية التي تحتوي على روابط لجميع الصفحات الأخرى
- **login.html** - صفحة تسجيل الدخول
- **signup.html** - صفحة إنشاء حساب جديد
- **chat.html** - صفحة الدردشة الأساسية
- **admin.html** - لوحة تحكم المدير
- **contact.html** - نموذج للاتصال والتواصل

### 2. ملفات التنسيق (CSS)

- **style.css** - ملف CSS موحد لجميع صفحات الموقع مع تحسينات للتصميم وتجربة المستخدم

### 3. ملفات الجافاسكريبت (JS)

- **app.js** - ملف جافاسكريبت مركزي يحتوي على جميع الوظائف البرمجية للموقع

## مميزات التطبيق

1. **نظام المصادقة**:
   - تسجيل الدخول للمستخدمين
   - إنشاء حسابات جديدة
   - مستويات مختلفة للمستخدمين (مدير ومستخدم عادي)

2. **نظام الدردشة**:
   - إرسال واستقبال الرسائل
   - عرض مؤقت للزمن
   - ردود آلية للمحادثة

3. **لوحة تحكم المدير**:
   - إدارة المستخدمين
   - إحصائيات المحادثات
   - إعدادات النظام

4. **تخزين البيانات**:
   - استخدام localStorage لتخزين بيانات المستخدمين والمحادثات
   - حفظ الجلسة الحالية

## حسابات المستخدمين الافتراضية

تم إنشاء حسابات افتراضية للاختبار:

1. **حساب المدير**:
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

2. **حساب مستخدم عادي**:
   - اسم المستخدم: `user1`
   - كلمة المرور: `user123`

## تعليمات الاستخدام

### للمستخدم العادي:

1. الدخول للصفحة الرئيسية `index.html`
2. النقر على "تسجيل الدخول" أو "إنشاء حساب جديد"
3. بعد تسجيل الدخول، يمكن الدخول إلى صفحة الدردشة
4. يمكن إرسال رسائل جديدة من خلال صندوق النص في أسفل الشاشة

### للمدير:

1. تسجيل الدخول باستخدام حساب المدير
2. سيتم توجيهك تلقائيًا إلى لوحة التحكم
3. يمكن إدارة المستخدمين عبر زر "إدارة المستخدمين"
4. يمكن عرض إحصائيات المحادثات عبر زر "إحصائيات المحادثات"

## ملاحظات فنية

1. **تخزين البيانات**: يستخدم التطبيق localStorage لتخزين البيانات، مما يعني أن البيانات ستبقى محفوظة في متصفح المستخدم حتى بعد إغلاق المتصفح.

2. **الأمان**: هذا الإصدار مخصص للعرض والتجريب فقط. في الإصدار الإنتاجي يجب استخدام تقنيات أمان أفضل مثل HTTPS وتشفير كلمات المرور.

3. **التصميم**: تم تحسين التصميم ليكون متجاوبًا مع جميع أحجام الشاشات بما في ذلك الأجهزة المحمولة.
